# BioPlot 热图图片修改器（本地原型）

## 启动

直接用现代浏览器打开 `index.html`，无需安装依赖、无需启动服务器。网页不会把数据上传到网络。

## 完整流程

1. 上传 TSV/CSV 表达矩阵，首列为蛋白 ID，其余列为数值样本；或点击“载入示例数据”。
2. 选择行 Z-score、原值或行 Min-Max；可设置缺失值、色阶、聚类和图形标签。
3. 在画布中查看重绘预览。
4. 选择 PNG 导出倍率，点击“导出 PNG”。

## 说明

- 所有侧栏控件均有对应行为；文件错误会显示在顶部状态栏。
- 浏览器端实现矩阵读取、行标准化、行/列层次聚类和 PNG 绘制，方便先体验完整交互。
- 本原型的聚类方法使用浏览器端实现，适合验证界面和中小型数据；它不是 R `pheatmap`/`ComplexHeatmap` 的像素级复刻。
- 云端正式版本可以将计算函数替换为 R/Shiny 服务，并继续保留本界面和参数设计。
- 目前只导出 PNG，不产生 PDF/SVG。
